Ultimate Guitar and Spotify don't talk to each other, which is annoying if you're learning songs and want to actually listen to them. UGtoSpotify bridges that gap — authenticate with Spotify, paste your Ultimate Guitar playlist, and get a Spotify playlist back. Built with vanilla JavaScript and Netlify serverless functions to handle OAuth 2.0 flows and proxy API requests around CORS restrictions. Integrates two third-party APIs with entirely different authentication schemes and maps song data between them.
