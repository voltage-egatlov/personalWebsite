Built to scratch a personal itch for browser-based sound design, 7eSynth turns a standard keyboard into a playable synthesizer — no plugins, no downloads. It runs entirely in the browser using the Web Audio API and React, handling real-time oscillator control, note mapping, and envelope management with low enough latency to actually be usable as an instrument. Supports both keyboard and click input, built with TypeScript throughout, and deployed on Netlify.
